# ATLAS — cliente web

Protótipo do cliente web do jogo ATLAS — Conquista Territorial.
As regras, o visual aprovado e o código do servidor ficam no repositório privado `atlas`.

Publicado por GitHub Pages. Abra pelo celular para usar o GPS real.
Acrescente `?sim=1` ao endereço para simular leituras de GPS tocando no mapa.
